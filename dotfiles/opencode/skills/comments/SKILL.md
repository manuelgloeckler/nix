# Apply Code Review Comments

Read `.code-review.md` in the repo root and apply every comment in order, top to bottom.

For each comment section:
- The heading has the file path and line range (for example `src/main.rs:10-15`).
- Read the referenced file for context; do not match only the snippet.
- Apply the change described in the comment text.
- Look for TODO markers or hints inside the comment and act on them.

When done, delete `.code-review.md` — this signals to code-review.nvim that the review
is complete. Then summarize one line per comment: applied, skipped, or already resolved.
